# nikasadriiii/credit-card-fraud-detection
Credit Card Fraud Detection — Python, Scikit-learn, SMOTE, Random Forest, SQL Built an end-to-end fraud detection pipeline on a highly imbalanced credit-card transaction dataset; applied SMOTE to training data, compared Logistic Regression and Random Forest models, and evaluated performance using precision, recall, F1-score, and PR-AUC.
